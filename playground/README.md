# ⚠️ Deprecated

> **nuxt-simple-auth** has been **deprecated** and is no longer under active development.

This package has been replaced by **nuxt-umbu**, which provides:

- ✅ Full authentication support for Nuxt
- ✅ Laravel Passport & Sanctum
- ✅ Two-Factor Authentication (2FA)
- ✅ SSR authentication
- ✅ Multiple authentication strategies
- ✅ Improved API
- ✅ Active maintenance and new features

## 🚀 Migrate to nuxt-umbu

Please migrate your projects to **nuxt-umbu**.

- 📦 npm: https://www.npmjs.com/package/nuxt-umbu
- 🐙 GitHub: https://github.com/4sllan/nuxt-umbu
- 📖 Documentation: https://4sllan.github.io/nuxt-umbu/

## Installation

```bash
npx nuxi@latest module add nuxt-umbu
```

Thank you to everyone who used and contributed to **nuxt-simple-auth** ❤️.
All future development will happen in **nuxt-umbu**.
